# Amul Blueberry Protein Shake - Animated Website 🫐💪

An interactive 3D canvas scroll website showcasing the Amul Blueberry Protein Shake.

## Features
- **Interactive 3D Frame Engine**: Smooth scroll-driven canvas animation powered by pre-rendered frame sequences.
- **Ultra-Responsive Layout**: Adapts smoothly to desktop, tablet, and mobile devices.
- **Fast Performance & High Caching**: Pre-loaded frame buffers and CDN caching optimized for zero lag.
- **Vercel & Static Host Ready**: Zero-config deployment on Vercel, Netlify, GitHub Pages, or Node.js.

## Local Development

### Option 1: Direct File / Static Server
Open `index.html` in any browser or use Live Server.

### Option 2: Node.js Server
Run local server with cross-device preview (Wi-Fi test):
```bash
npm start
```
Open `http://localhost:3000` in your browser.

## Deploying to Vercel

### Method 1: GitHub Integration (Recommended)
1. Push this repository to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import the repository `Amul-website-`.
4. Click **Deploy**. Vercel will automatically detect the static project and deploy it instantly!

### Method 2: Vercel CLI
```bash
npm i -g vercel
vercel
```
